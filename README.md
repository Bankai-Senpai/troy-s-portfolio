# Troy Sacote Portfolio

A Vite-powered portfolio site with a galaxy-inspired visual design, profile image, project sections, workflow demos, and a local interactive chatbot experience.

## Local Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

The production output is generated in `dist/`.

## Vercel

This project includes `vercel.json` with the recommended settings:

- Framework: Vite
- Build command: `pnpm build`
- Output directory: `dist`
